Formulários HTML

Oque são formulários no HTML?

Os formulários são uma das partas mais importantes do HTML pois ajudam a introduzir uma ideia diferente.

O usuário deixa de apenas consumir conteúdo e passa a fornecer dados para o sistema.

Um formulário, de forma resumida, é uma área da página destinada a coleta de informações.

Exemplos de uso:

  • Login
  • Cadastro
  • Contato
  • Pesquisa
  • Comentários
  • Endereço
  • Incrições em Newsletter

Criando um formulário básico

  • < label > : Representa um rótulo;etiqueta para um campo. É um recurso fundamental para a acessibilidade.
  • for : Para conectarmos o nosso rótulo (label) ao input, utilizamos o atributo for. Ele serve para criar a relação com o id do input.
  • id : O atributo ID serve para identificar de forma única um elemento dentro da página.
  • type : Esse atributo serve para definirmos o tipo de input que desejamos apresentar para o usuário com base no dado que queremos coletar.
