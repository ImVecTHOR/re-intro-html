  • target : Especifica onde abrir o link configurado no href (hypertext reference = referência de hipertexto).
  • _blank : Este valor inidca que o conteúdo será aberto em uma nova aba do navegador.
  • _self : Este valor indica que o conteúdo será aberto aberto na aba onde o conteúdo atual está aberto.
  • _parent : Este conteúdo indica que o conteúdo será aberto no contexto do pai do documento atual.
  • _top : Este valor indica que o conteúdo será exibido no contexto do elemento pai de nível mais alto da página.
